# Components reference

Generated by `npm run docs` from the component code. Each scene in scenes.yaml uses exactly one component.

Common to every scene: `id` (S01, S02…), `component`, `say` (narration, speech-ready), optional `chapter` (YouTube chapter name), `params`.
Timing: any `cue` / `*_cue` value is a short phrase copied **exactly** from that scene's `say`; the element appears when that phrase is spoken. Without a cue, items are spread evenly through the scene.
Text fields accept `$inline LaTeX$`, `**bold**`, `==yellow marker==`, `{red}red text{/red}`. `tex` fields are LaTeX without dollar signs (escape backslashes in YAML double quotes: `"\\frac{a}{b}"`).
Colors by brand name: navy, ink, red, blue, green, marker, muted, grid (or hex). Icons: Tabler outline names (tabler.io/icons).

## Shared (any style)

### `big-fact`
One huge number or short statement with a label: the surprising fact of a hook. Optional count-up animation.

- `value` **(required)**: text shown, e.g. '4×' or '$614,000' (required)
- `count`: optional {from, to, decimals?, prefix?, suffix?} to count up instead of showing value
- `label`: text above
- `sub`: text below
- `navy`: true for navy background
- `cue`: when the number appears

### `bullets`
Heading plus 2–5 short points that appear one by one, each optionally with an icon. Points support $math$, **bold**, ==marker==.

- `heading`: text
- `items` **(required)**: list of {text, icon?: tabler icon name, cue?}

### `end-card` (navy background)
Navy end screen with the logo and two empty slots where YouTube's end-screen video and subscribe elements sit. Always the last scene (5–20 s).

- `line`: short closing line, e.g. 'Next: why highway curves aren't circles'

### `image`
Full-frame photo with a slow zoom and optional caption. treatment 'archive' gives an old-photo look for history stories.

- `src` **(required)**: file in the video's assets/ folder (required)
- `caption`: short caption
- `credit`: photo credit (required for licensed images)
- `zoom`: in | out | none (default in)
- `focus`: [x%, y%] zoom centre
- `treatment`: none | archive

### `title-card` (navy background)
Navy title card: big title, optional kicker above and subtitle below. Use for the opening title or a chapter break.

- `title` **(required)**: text (required)
- `kicker`: small text above
- `subtitle`: text below
- `cue`: when it appears

## Style A · Whiteboard Build

### `diagram`
A whiteboard drawing built item by item: lines, arrows, shapes, labels, math, icons, dimensions, angles, forces, supports, ground. Also used for free-body diagrams (style F).

- `heading`: text
- `view`: [width, height] coordinate space, default [1000, 600]; (0,0) is top-left
- `items` **(required)**: list of items, each with type and cue?: line|arrow {from,to,label?}, rect {pos,size,label?,fill?}, circle {pos,r,label?,fill?}, polyline|polygon {points}, path {d}, text {pos,text,hand?,size?: s|l|xl,anchor?}, tex {pos,tex,size?}, icon {pos,name,size?}, dim {from,to,label}, angle {pos,from_deg,to_deg,r?,label}, force {pos,angle,length?,label,tail?}, support {pos,kind: pin|roller|fixed,side?}, ground {from,to}. Common: color (brand name or hex), width, dashed
- `caption`: text under the drawing

### `equation-steps`
Equations built line by line on the whiteboard, with yellow marker, red circle, red handwritten note and boxed answer options. Optional figure beside the lines. Also used for numbered solution steps in style F.

- `heading`: text
- `lines` **(required)**: list of {tex | text, cue?, label? (e.g. 'Step 1'), mark?: true, circle?: true, note?: 'red side note', box?: true (final answer), mark_cue?, circle_cue?, note_cue?}
- `figure`: optional {view:[w,h], items:[diagram items]} shown beside the lines
- `figure_side`: left | right (default left)
- `size`: m | l (bigger math for short derivations)

### `table`
Data table whose rows appear one by one, with an optional highlighted cell or row. For values, comparisons, simplex tableaux, results.

- `heading`: text
- `headers` **(required)**: list of column headers (text or $math$)
- `rows` **(required)**: list of rows, each a list of cells (text or $math$)
- `row_cues`: optional list of cue phrases, one per row
- `highlight`: optional {row, col?, cue?} (0-based); highlights a cell, or the whole row if col is omitted

## Style B · Real-World Overlay

### `photo-overlay`
Real photo of the everyday object with animated engineering overlays on top: measurement lines, arrows, callouts, labels, highlight boxes and math cards. The signature hook style.

- `src` **(required)**: photo in the video's assets/ folder (required)
- `credit`: photo credit / license (required for anything not your own)
- `zoom`: in | out | none (default in, gentle)
- `focus`: [x%, y%] zoom centre
- `shade`: 0–0.7 darkening so overlays stand out (default 0.25)
- `title`: optional banner text at the top
- `overlays`: list, coordinates in % of the frame (0–100), each with cue?: measure {from,to,label}, arrow {from,to,label?}, callout {pos,text,side?: left|right}, label {pos,text}, box {pos,size,label?}, tex {pos,tex}

## Style C · Graph Lab

### `graph`
Animated function plot: axes, curves that draw themselves, shaded area under a curve, labelled points, reference lines and a dot that travels along a curve. For calculus, growth/decay, waves, vibration, queueing curves.

- `heading`: text
- `x_range` **(required)**: [min, max]
- `y_range` **(required)**: [min, max]
- `x_label`: axis label ($math$ ok)
- `y_label`: axis label
- `functions`: list of {expr (JavaScript math in x, e.g. 'x^2/(2*7)', 'exp(-0.3*x)*cos(3*x)'), label? ($math$), color?, dashed?, cue?, from?, to?}
- `area`: optional {expr, from, to, label?, cue?} shaded area under a curve
- `points`: optional list of {x, y, label?, cue?}
- `hlines`: optional list of {y, label?, cue?}
- `vlines`: optional list of {x, label?, cue?}
- `tracer`: optional {expr, from, to, cue?, duration? (s), label?} dot that travels along the curve
- `side`: optional list of {tex, cue?} equations shown beside the graph

## Style D · Story / Case Study

### `quote`
A short quote from a person or report, with attribution. Keep quotes short and accurate; cite the source.

- `text` **(required)**: the quote (required)
- `who`: person or source
- `source`: where it was said/published
- `cue`: when it appears

### `timeline`
Horizontal timeline of a real event or a person's story; each event appears when spoken.

- `heading`: text
- `events` **(required)**: list of {when (e.g. '1940' or '10 June 2000'), text, cue?}

## Style E · Shorts

### `short-end` (navy background)
Vertical end card for Shorts: logo + 'Full video on the channel'. Added automatically by `npm run shorts`; not used in scenes.yaml.

- `text`: line under the logo

## Style F · Engineering Problem Solver

### `answer-box`
Boxed final answer with units, then an optional 'does this make sense?' check line.

- `label`: e.g. 'Answer'
- `tex` **(required)**: the answer in LaTeX with units (required)
- `check`: optional sanity-check sentence
- `cue`: answer cue
- `check_cue`: check cue

### `beam`
Beam problem drawn and SOLVED automatically: loads and supports, reactions, then shear-force (V) and bending-moment (M) diagrams with peak values. Statically determinate beams only (two pin/roller supports, or one fixed end).

- `length` **(required)**: beam length (number, required)
- `unit_len`: e.g. 'm'
- `unit_force`: e.g. 'kN'
- `supports` **(required)**: list of {type: pin|roller|fixed, x}
- `loads` **(required)**: list of {type: point, x, P} | {type: udl, x1, x2, w} | {type: moment, x, M}; downward P/w positive, M counter-clockwise positive
- `show`: which panels, default [beam, shear, moment]; add 'reactions' to label reaction values
- `cues`: optional {beam?, reactions?, shear?, moment?} cue phrases
- `heading`: text

### `pause-try` (navy background)
'Pause and try it' moment with a countdown ring, before the solution. Keep the narration short here (or silent seconds).

- `text`: default 'Pause the video and try it'
- `seconds`: countdown length, default 5

### `problem-card`
Textbook-style problem statement: figure on one side, Given / Find / Assumptions on the other. Opens every solved engineering problem (and the practice problem at the end).

- `title`: e.g. 'Problem 1' or 'Practice problem'
- `figure`: optional {view:[w,h], items:[diagram items]}
- `given` **(required)**: list of text/$math$ items
- `find` **(required)**: list of text/$math$ items
- `assumptions`: optional list
- `cues`: optional {given?, find?, assumptions?} cue phrases
